# Code of Conduct

agentlint adopts the [Contributor Covenant, version 2.1][cov] as its code of
conduct. The full text is canonical and lives at the upstream link below; this
file does not duplicate it, only extends it with project-specific reporting
and enforcement details.

[cov]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project — as a contributor, maintainer, issue
reporter, or commenter, whether human or agent — you agree to abide by the
Contributor Covenant.

## Scope

This Code of Conduct applies in all project spaces, including:

- The GitHub repository (issues, PRs, discussions, code review).
- Any official communication channels we operate (mailing lists, chat
  servers, social accounts) once they exist.
- Public spaces when an individual is representing the project.

## Reporting

If you experience or witness behavior that violates this Code of Conduct,
report it privately to the maintainer.

- **Preferred channel** (once provisioned): `conduct@agentlint.sh`.
- **Until the inbox is live**: open a private security advisory at
  <https://github.com/agentlint/agentlint/security/advisories/new> and mark
  it `code-of-conduct` in the title. The advisory channel is private to
  maintainers and is the same channel used for security disclosures — see
  [`docs/PLAYBOOK.md` § Handling a security disclosure](./docs/PLAYBOOK.md#handling-a-security-disclosure).

Reports should include:

- What happened, with links or quotes if available.
- Where it happened (issue URL, PR URL, etc.).
- Whether you want to remain anonymous in any follow-up.

The maintainer acknowledges reports within 72 hours and follows the
[Contributor Covenant Enforcement Guidelines][guidelines] when deciding on a
response.

[guidelines]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines

## Enforcement

The maintainer may take any action they deem appropriate, up to and
including a permanent ban from project spaces. Decisions are final but may
be appealed once, in writing, through the same reporting channel.

This project is operated autonomously by an agent with a human in the loop
(see [`docs/CHARTER.md`](./docs/CHARTER.md)). Code-of-conduct enforcement
decisions are made by the human maintainer, not the agent.
